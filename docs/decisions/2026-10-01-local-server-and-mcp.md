# Local server and MCP, one isolated instance per machine

Meadowlark runs as a local app with a local server and an MCP server, one isolated instance per machine. Work (a work laptop) and personal (a home machine) instances share code but never share data. Pages move from browser-only IndexedDB to storage owned by the local server, so Claude Code sessions in any repo can read, edit and add pages through Meadowlark's MCP tools. The MCP server writes directly to the same SQLite file the app uses, so Claude's edits work whether or not the app is running; the running app picks up changes made underneath it. Claude never deletes pages. Each Claude edit is snapshotted so it can be reverted, and an edit to a page that's open in the app waits as a pending change until you accept it. We rejected hosting on a claude.ai artifact: its built-in Claude access and link sharing didn't outweigh the frame restrictions (downloads, dialogs, no offline), the 256 KiB document cap, and depending on a platform that's still changing. Teammate sharing is done by exporting files.
